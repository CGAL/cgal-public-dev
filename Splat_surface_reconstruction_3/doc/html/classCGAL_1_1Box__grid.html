Detailed Description

template<typename Kernel_>
class CGAL::Box_grid< Kernel_ >

Dense axis-aligned box grid over a fixed 3D domain.

The grid stores points and accumulated normals per cell. It is used as a local acceleration structure for neighborhood queries, cell-normal estimation, and adaptive splat-size estimation.

Template Parameters
Kernel_CGAL kernel type used for points, vectors, and scalars.

inline

Estimates one splat size per point using local 2D triangulation.

For each point, the method:

  • finds the point's cell,
  • projects neighbors to the tangent plane,
  • builds a local Delaunay triangulation in 2D,
  • measures the farthest circumcenter distance.
Parameters
global_spacingDefault splat size used as fallback.
Returns
A vector of per-point splat radii.

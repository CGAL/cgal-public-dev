Since, the algorithm requires a splat associated with each point, this class is a per-sample record and stores all the infromation associated with a point.
class PointRecord
  - Vec3 position
  - Vec3 normal
  - float splatRadius // shift it to SplatRADIUS
  - int id
  - int boxId // the id of box the point lies in

Stores all the points and corresponding normals
class PointCloud
  - vector<PointRecord> points
  - estimateNormals()            // optional if normals missing

This represents the local sphere/patch around a point. It is used when computing candidate positions.
class Splat   // (could be property of CGAL point set)
  - int id  // the id matches the center point id
  - Vec3 center // not needed
  - Vec3 normal // not needed
  - float radius 
  - bool contains(Vec3 x)
  - Vec3 generateCandidates(Vec3 parentA, Vec3 parentB, float targetEdgeLength)

  - int suggestedSplatId

Priority for each vertex candidate
// Separate in different lists of FIFO and priority queues (the first 3 might not have inherent priority)
enum class CandidatePriority
  - StartVertexParent // bounded by 12-13 candidates
  - DegreeOneParent
  - JoinBorders
  - SplitBorders // this has additional integer in range [1,window_size]
